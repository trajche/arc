Arc, in Firefox

Your tabs live in the sidebar now. Hover a feature to see where it lives.

Coming from Arc? Import your spaces, pinned tabs and favorites.

Favorites

Drag a tab into the grid at the top. Each favorite keeps its own tab, and closing it leaves the icon in place.

Spaces

Separate sets of tabs, each with its own color and, if you want, its own logins. Switch from the footer, by swiping, or with ⌃1–⌃5.

Pinned tabs and folders

Drag tabs above the line to pin them to a space. Shift- or Command-click several, then right-click and choose New Folder.

Command bar

⌘T opens a search box instead of a blank page. Type a site, a search, or the name of an open tab.

Address bar in the sidebar

Shows the site you’re on. Click it to edit the address or search. ⌥⇧L jumps there.

Hide the sidebar

⌥⇧S gives the page the whole window. Press it again to bring your tabs back.

Split view

Two tabs side by side show as one row. Add one with Firefox’s Add Split View shortcut, which you can set in about:keyboard.

Extensions row

Your pinned extensions sit under the window buttons, once the layout below is set up.

Give Arc the whole window

Firefox doesn’t let extensions hide its own tab strip and toolbar. A small setup script does it once: it finds the Firefox profile with Arc and adds Arc’s layout, keeping any customizations you already have.

Paste this into Terminal, then quit Firefox and open it again:

curl -fsSL https://raw.githubusercontent.com/trajche/arc/main/extras/setup/arc-setup.txt | bash

Or download the script to read it first.

Paste this into PowerShell, then quit Firefox and open it again:

irm https://raw.githubusercontent.com/trajche/arc/main/extras/setup/arc-setup.ps1 | iex

Or download the script to read it first.

Run it again after updating Arc to refresh the layout.
